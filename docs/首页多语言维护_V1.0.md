# 首页多语言维护

本轮范围：首页、公共导航和首页页脚。简体中文 `/zh/`、English `/en/` 保留原有内容；新增繁體中文 `/zh-Hant/`、日本語 `/ja/`。未翻译的内页沿用现有中文或英文页面，不生成空白的繁体或日语内页。

## 文件与职责

- `src/lib/languages.ts`：语言清单、语言标签、首页地址，以及底稿语言的对应关系。
- `src/data/home-ja.ts`：日语首页和公共导航译文，包括看板、隐藏页签、无障碍标签、逐字输出内容。
- `src/lib/localize-home.ts`：解析构建出的 HTML，仅转换文字及指定文案属性；脚本、样式、语言选项原文和业务链接保留。
- `src/middleware.ts`：仅在预渲染 `/zh-Hant/`、`/ja/` 时转换响应。翻译依赖不会发送到浏览器。
- `src/components/navigation/SiteHeader.astro`：四语言下拉、当前语言标记与登录入口。

繁体使用 OpenCC 的 `cn → tw` 字形转换；日语以英文首页为底稿，用明确译文替换。修改英文首页或导航文案时，同步更新对应日语词条，并核对生成页面。未来翻译内页时，再扩展对应路由和内容类型，不把当前首页的覆盖范围当作全站支持。

## 核对

运行 `npm run check`、`npm run build`、`npm run verify`。打开四个首页，检查语言切换、菜单、登录入口、看板页签和逐字输出；手机端检查登录与语言入口是否挤压。自动检查不替代日语母语审校。
